# Commit 2/5 — Seeder: un usuario de cada rol

**Rama de trabajo:** `database`  
**Accion:** modificar archivo (reemplazar contenido completo)

## Por que (contexto)

Un usuario de cada rol para poder probar/demostrar la seguridad por
roles sin tener que registrar cuentas manualmente. La contraseña de
los tres, por default de la factory de Laravel, es literalmente
"password" — anotalo, lo van a necesitar para la demo.


> **Nota:** La password real depende de UserFactory (por default Laravel la deja en 'password' hasheada). Si alguien la cambio, usa esa.


## Codigo


**Archivo:** `database/seeders/DatabaseSeeder.php`

```php
<?php

namespace Database\Seeders;

use App\Models\User;
use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        User::factory()->create([
            'name' => 'Admin UTP',
            'email' => 'admin@example.com',
            'role' => 'admin',
        ]);

        User::factory()->create([
            'name' => 'Freelancer Demo',
            'email' => 'freelancer@example.com',
            'role' => 'freelancer',
        ]);

        User::factory()->create([
            'name' => 'Cliente Demo',
            'email' => 'cliente@example.com',
            'role' => 'cliente',
        ]);

        $this->call([
            CategorySeeder::class,
            ServiceSeeder::class,
        ]);
    }
}
```
