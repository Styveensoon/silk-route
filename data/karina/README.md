# Karina — Frontend (rama `frontend`)

**Espera a que `backend` de Styveen este COMPLETO y fusionado a
`main`.** A diferencia de Producto 02, aqui no hay nada que puedas
adelantar en paralelo: todas tus paginas dependen de rutas, roles y
campos que Styveen agrega.

Antes de empezar:
```powershell
git checkout main
git pull origin main
git checkout frontend
git merge main
```

Ejecuta 1.md a 9.md en orden. Al terminar el 9:
```powershell
git push origin frontend
```
Y abres el Pull Request `frontend -> main`.
