# Commit 4/8 — Registrar el binding del repositorio

**Rama de trabajo:** `backend`  
**Accion:** modificar archivo (reemplazar contenido completo)

## Por que (contexto)

Le decimos al contenedor de Laravel: "cuando alguien pida
ServiceRepositoryInterface, dale una instancia de
EloquentServiceRepository". Esto es lo que permite hacer mocks en tests
sin tocar la logica de negocio (justificado en Producto 01, seccion 4,
Mantenibilidad).


## Codigo


**Archivo:** `app/Providers/AppServiceProvider.php`

```php
<?php

namespace App\Providers;

use App\Repositories\EloquentServiceRepository;
use App\Repositories\ServiceRepositoryInterface;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    /**
     * Register any application services.
     */
    public function register(): void
    {
        $this->app->bind(ServiceRepositoryInterface::class, EloquentServiceRepository::class);
    }

    /**
     * Bootstrap any application services.
     */
    public function boot(): void
    {
        //
    }
}
```
