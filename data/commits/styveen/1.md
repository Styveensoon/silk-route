# Commit 1/8 — Modelo Category

**Rama de trabajo:** `backend`  
**Accion:** crear archivo

## Por que (contexto)

Modelo Eloquent para la tabla `categories` que creo Galo. La relacion
`services()` nos sirve mas adelante si queremos mostrar cuantos
servicios tiene una categoria.


## Codigo


**Archivo:** `app/Models/Category.php`

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Category extends Model
{
    protected $fillable = [
        'name',
        'slug',
    ];

    public function services()
    {
        return $this->hasMany(Service::class);
    }
}
```
