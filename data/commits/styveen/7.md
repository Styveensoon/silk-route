# Commit 7/8 — ServiceController + rutas

**Rama de trabajo:** `backend`  
**Accion:** crear 1 archivo y modificar otro

## Por que (contexto)

El controlador solo recibe la peticion HTTP y devuelve la respuesta
(Producto 01, seccion 5.2): toda la logica real ya vive en
ServiceService. Las 3 rutas nuevas son el contrato que va a consumir
Karina en el frontend: GET /services (listado), GET /services/create
(formulario), POST /services (publicar).


## Codigo


**Archivo:** `app/Http/Controllers/ServiceController.php`

```php
<?php

namespace App\Http\Controllers;

use App\Http\Requests\StoreServiceRequest;
use App\Services\ServiceService;
use Inertia\Inertia;
use Inertia\Response;

class ServiceController extends Controller
{
    public function __construct(
        protected ServiceService $serviceService
    ) {}

    public function index(): Response
    {
        return Inertia::render('Services/Index', [
            'services' => $this->serviceService->listActiveServices(),
        ]);
    }

    public function create(): Response
    {
        return Inertia::render('Services/Create', [
            'categories' => $this->serviceService->categories(),
        ]);
    }

    public function store(StoreServiceRequest $request)
    {
        $this->serviceService->publish($request->validated());

        return redirect()->route('services.index')
            ->with('success', 'Servicio publicado correctamente.');
    }
}
```


**Archivo:** `routes/web.php`

```php
<?php

use App\Http\Controllers\ServiceController;
use Illuminate\Support\Facades\Route;
use Inertia\Inertia;

Route::get('/', function () {
    return Inertia::render('Home');
});

Route::get('/services', [ServiceController::class, 'index'])->name('services.index');
Route::get('/services/create', [ServiceController::class, 'create'])->name('services.create');
Route::post('/services', [ServiceController::class, 'store'])->name('services.store');
```
