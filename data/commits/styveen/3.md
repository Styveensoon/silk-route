# Commit 3/8 — Repository Pattern: interfaz + implementacion Eloquent

**Rama de trabajo:** `backend`  
**Accion:** crear 2 archivos

## Por que (contexto)

Esto es el Repository Pattern que ya justificamos en el Producto 01
(seccion 5.1): la capa de servicio (commit 5) solo va a conocer la
interfaz, no el Eloquent concreto. Si un dia cambiamos el ORM, solo se
toca `EloquentServiceRepository`.


## Codigo


**Archivo:** `app/Repositories/ServiceRepositoryInterface.php`

```php
<?php

namespace App\Repositories;

use App\Models\Service;
use Illuminate\Database\Eloquent\Collection;

interface ServiceRepositoryInterface
{
    public function all(): Collection;

    public function create(array $data): Service;
}
```


**Archivo:** `app/Repositories/EloquentServiceRepository.php`

```php
<?php

namespace App\Repositories;

use App\Models\Service;
use Illuminate\Database\Eloquent\Collection;

class EloquentServiceRepository implements ServiceRepositoryInterface
{
    public function all(): Collection
    {
        return Service::with(['user', 'category'])
            ->where('status', 'active')
            ->latest()
            ->get();
    }

    public function create(array $data): Service
    {
        return Service::create($data);
    }
}
```
