# Commit 4/8 — Pagina de listado de servicios

**Rama de trabajo:** `frontend`  
**Accion:** crear archivo

## Por que (contexto)

Consume la ruta GET /services de Styveen (Inertia::render('Services/Index',
['services' => ...])). Por eso este commit necesita que backend ya
este fusionado a main: si el archivo no existe todavia del lado del
servidor, esta pagina no tiene nada que renderizar.


> **Nota:** Antes de este commit, asegurate de haber hecho el merge de main descrito en el README de tu carpeta (para traer las rutas y el controlador de Styveen).


## Codigo


**Archivo:** `resources/js/pages/Services/Index.vue`

```vue
<template>
  <AppLayout>
    <h1 class="text-2xl font-bold text-gray-900 mb-6">Servicios disponibles</h1>

    <div v-if="services.length === 0" class="text-gray-500">
      Aun no hay servicios publicados.
    </div>

    <div v-else class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">
      <ServiceCard v-for="service in services" :key="service.id" :service="service" />
    </div>
  </AppLayout>
</template>

<script setup>
import AppLayout from '../../Layouts/AppLayout.vue';
import ServiceCard from '../../Components/ServiceCard.vue';

defineProps({
  services: { type: Array, default: () => [] },
});
</script>
```
