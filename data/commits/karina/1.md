# Commit 1/8 — Corregir bug de mayusculas en la resolucion de paginas Inertia

**Rama de trabajo:** `frontend`  
**Accion:** modificar archivo (reemplazar contenido completo)

## Por que (contexto)

Bug real que encontramos revisando el repo: `app.js` buscaba las
paginas en `./Pages/` (con mayuscula) pero la carpeta que existe de
verdad es `resources/js/pages/` (minuscula). En Windows no truena
porque el sistema de archivos no distingue mayusculas/minusculas, pero
en un servidor Linux (como el Raspberry Pi de Styveen, o cualquier
hosting) si truena. Lo arreglamos antes de agregar paginas nuevas.


## Codigo


**Archivo:** `resources/js/app.js`

```js
import './bootstrap';
import '../css/app.css';
import { createApp, h } from 'vue';
import { createInertiaApp } from '@inertiajs/vue3';

createInertiaApp({
    resolve: name => {
        const pages = import.meta.glob('./pages/**/*.vue', { eager: true });
        return pages[`./pages/${name}.vue`];
    },
    setup({ el, App, props, plugin }) {
        createApp({ render: () => h(App, props) })
            .use(plugin)
            .mount(el);
    },
});
```
