# Commit 2/8 — Seeder de categorias base

**Rama de trabajo:** `database`  
**Accion:** crear archivo

## Por que (contexto)

Seeder con las 5 categorias base del marketplace, tomadas de los actores
y requerimientos del Producto 01. Usa `firstOrCreate` para que se pueda
correr mas de una vez sin duplicar filas.

Este archivo referencia el modelo `App\Models\Category`, que Styveen
crea en su commit 1 (rama backend). No pasa nada si en este momento el
modelo no existe todavia en tu rama: el seeder no se ejecuta al hacer el
commit, solo se ejecutara despues con `php artisan db:seed`, y para
entonces backend ya estara fusionado a main.


## Codigo


**Archivo:** `database/seeders/CategorySeeder.php`

```php
<?php

namespace Database\Seeders;

use App\Models\Category;
use Illuminate\Database\Seeder;
use Illuminate\Support\Str;

class CategorySeeder extends Seeder
{
    public function run(): void
    {
        $categories = [
            'Diseño grafico',
            'Desarrollo web',
            'Tutorias academicas',
            'Redaccion y edicion',
            'Edicion de video',
        ];

        foreach ($categories as $name) {
            Category::query()->firstOrCreate(
                ['slug' => Str::slug($name)],
                ['name' => $name]
            );
        }
    }
}
```
