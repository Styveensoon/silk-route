# Commit 3/8 — Migracion de la tabla services

**Rama de trabajo:** `database`  
**Accion:** crear archivo

## Por que (contexto)

Tabla central del modulo. `user_id` referencia al freelancer que publica
(si se borra el usuario, se borran sus servicios). `category_id`
referencia a categories con `restrictOnDelete` (no se puede borrar una
categoria que tiene servicios activos, para no dejar datos huerfanos).
`status` es string simple ('active' por defecto) en vez de un enum de
base de datos, para no complicar migraciones futuras si se agregan mas
estados.
