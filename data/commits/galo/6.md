# Commit 6/8 — Registrar los seeders nuevos en DatabaseSeeder

**Rama de trabajo:** `database`  
**Accion:** modificar archivo (reemplazar contenido completo)

## Por que (contexto)

El orden del arreglo importa: CategorySeeder debe ir primero porque
ServiceFactory (commit 4) depende de que ya existan categorias.


## Codigo


**Archivo:** `database/seeders/DatabaseSeeder.php`

```php
<?php

namespace Database\Seeders;

use App\Models\User;
use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    /**
     * Seed the application's database.
     */
    public function run(): void
    {
        User::factory()->create([
            'name' => 'Test User',
            'email' => 'test@example.com',
        ]);

        $this->call([
            CategorySeeder::class,
            ServiceSeeder::class,
        ]);
    }
}
```
