# Commit 5/8 — Seeder de servicios de prueba

**Rama de trabajo:** `database`  
**Accion:** crear archivo

## Por que (contexto)

Crea 3 freelancers de prueba con 2 servicios cada uno (6 servicios en
total), para que el listado del frontend (commits de Karina) no se vea
vacio al hacer la demo.


## Codigo


**Archivo:** `database/seeders/ServiceSeeder.php`

```php
<?php

namespace Database\Seeders;

use App\Models\Service;
use App\Models\User;
use Illuminate\Database\Seeder;

class ServiceSeeder extends Seeder
{
    public function run(): void
    {
        $freelancers = User::factory()->count(3)->create();

        $freelancers->each(function (User $user) {
            Service::factory()
                ->count(2)
                ->create(['user_id' => $user->id]);
        });
    }
}
```
