# Commit 8/8 — Documentar el esquema del modulo de servicios

**Rama de trabajo:** `database`  
**Accion:** crear archivo

## Por que (contexto)

Documentacion corta del esquema para que el equipo (y quien revise el
proyecto) entienda las tablas sin tener que leer las migraciones una
por una.


## Codigo


**Archivo:** `database/SCHEMA.md`

```markdown
# Esquema — Modulo de Servicios

## Tabla `categories`

| Columna    | Tipo         | Notas             |
|------------|--------------|-------------------|
| id         | bigint PK    |                   |
| name       | string       |                   |
| slug       | string unico |                   |
| timestamps | -            | created_at/updated_at |

## Tabla `services`

| Columna     | Tipo           | Notas                                   |
|-------------|----------------|------------------------------------------|
| id          | bigint PK      |                                          |
| user_id     | FK -> users    | on delete cascade                       |
| category_id | FK -> categories | on delete restrict                    |
| title       | string         |                                          |
| description | text           |                                          |
| price       | decimal(8,2)   |                                          |
| status      | string         | 'active' \| 'paused' \| 'closed', default 'active' |
| timestamps  | -              |                                          |

Indice compuesto: `(category_id, status)` para acelerar el listado
filtrado (ver migracion `2026_08_02_100003`).

## Relaciones

- `User` 1—N `Service`
- `Category` 1—N `Service`
```
