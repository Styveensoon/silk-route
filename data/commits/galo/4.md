# Commit 4/8 — Factory de servicios para datos de prueba

**Rama de trabajo:** `database`  
**Accion:** crear archivo

## Por que (contexto)

Factory para generar servicios de prueba con Faker. `category_id` toma
una categoria existente al azar, por eso el seeder de categorias
(commit 2) siempre debe correr ANTES que el seeder de servicios
(commit 5) — eso se garantiza en el commit 6.


## Codigo


**Archivo:** `database/factories/ServiceFactory.php`

```php
<?php

namespace Database\Factories;

use App\Models\Category;
use App\Models\User;
use Illuminate\Database\Eloquent\Factories\Factory;

class ServiceFactory extends Factory
{
    public function definition(): array
    {
        return [
            'user_id' => User::factory(),
            'category_id' => Category::query()->inRandomOrder()->value('id'),
            'title' => ucfirst($this->faker->words(4, true)),
            'description' => $this->faker->paragraph(3),
            'price' => $this->faker->randomFloat(2, 100, 2500),
            'status' => 'active',
        ];
    }
}
```


## Comandos a ejecutar
