# Commit 6/11 — Administracion de usuarios (solo admin)

**Rama de trabajo:** `backend`  
**Accion:** crear 1 archivo y modificar otro

## Por que (contexto)

Modulo obligatorio de "Administracion de usuarios" de la rubrica,
separado de login/roles. Un admin puede ver todos los usuarios,
cambiarles el rol, o desactivarlos (is_active=false, que ya bloquea el
login gracias al commit 2). A proposito NO hay `destroy` de usuarios:
borrar un usuario borraria en cascada sus servicios, mejor desactivar.


## Codigo


**Archivo:** `app/Http/Controllers/AdminUserController.php`

```php
<?php

namespace App\Http\Controllers;

use App\Models\User;
use Illuminate\Http\Request;
use Inertia\Inertia;
use Inertia\Response;

class AdminUserController extends Controller
{
    public function index(): Response
    {
        return Inertia::render('Admin/Users', [
            'users' => User::orderBy('name')->get(['id', 'name', 'email', 'role', 'is_active']),
        ]);
    }

    public function update(Request $request, User $user)
    {
        $data = $request->validate([
            'role' => ['required', 'in:admin,freelancer,cliente'],
            'is_active' => ['required', 'boolean'],
        ]);

        $user->update($data);

        return back()->with('success', 'Usuario actualizado.');
    }
}
```


**Archivo:** `routes/web.php`

```php
<?php

use App\Http\Controllers\AdminUserController;
use App\Http\Controllers\CategoryController;
use App\Http\Controllers\ServiceController;
use Illuminate\Support\Facades\Route;
use Inertia\Inertia;

Route::get('/', function () {
    return Inertia::render('Home');
});

Route::get('/services', [ServiceController::class, 'index'])->name('services.index');
Route::get('/services/create', [ServiceController::class, 'create'])->name('services.create');
Route::post('/services', [ServiceController::class, 'store'])->name('services.store');
Route::get('/services/{service}/edit', [ServiceController::class, 'edit'])->name('services.edit');
Route::put('/services/{service}', [ServiceController::class, 'update'])->name('services.update');
Route::delete('/services/{service}', [ServiceController::class, 'destroy'])->name('services.destroy');

Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::resource('categories', CategoryController::class)->except(['show']);
    Route::get('/admin/users', [AdminUserController::class, 'index'])->name('admin.users.index');
    Route::put('/admin/users/{user}', [AdminUserController::class, 'update'])->name('admin.users.update');
});

require __DIR__.'/auth.php';
```
