# Commit 8/11 — Instalar Sanctum para autenticacion de la API

**Rama de trabajo:** `backend`  
**Accion:** ejecutar comando + modificar 2 archivos

## Por que (contexto)

`php artisan install:api` es el comando oficial de Laravel 11 para
dejar lista una API REST: crea `routes/api.php`, publica la migracion
de tokens de Sanctum, y modifica `bootstrap/app.php` agregando la
linea `api: __DIR__.'/../routes/api.php'` solo. Lo que el comando NO
hace automatico es agregar el trait `HasApiTokens` al modelo User —
eso se hace a mano (ya esta en el bloque de arriba).


> **Nota:** El bloque de bootstrap/app.php de arriba ya viene con la linea api: agregada — el comando install:api la deja asi solo, no necesitas escribirla a mano, solo confirma que quedo igual.


## Codigo


**Archivo:** `app/Models/User.php`

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens, HasFactory, Notifiable;

    protected $fillable = [
        'name',
        'email',
        'password',
        'role',
        'is_active',
    ];

    protected $hidden = [
        'password',
        'remember_token',
    ];

    protected function casts(): array
    {
        return [
            'email_verified_at' => 'datetime',
            'password' => 'hashed',
            'is_active' => 'boolean',
        ];
    }

    public function services()
    {
        return $this->hasMany(Service::class);
    }
}
```


**Archivo:** `bootstrap/app.php`

```php
<?php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->web(append: [
            \App\Http\Middleware\HandleInertiaRequests::class,
        ]);

        $middleware->alias([
            'role' => \App\Http\Middleware\EnsureUserHasRole::class,
        ]);
    })
    ->withExceptions(function (Exceptions $exceptions) {
        //
    })->create();
```
