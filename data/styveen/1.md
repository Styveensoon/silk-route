# Commit 1/11 — Instalar Laravel Breeze (stack Inertia + Vue)

**Rama de trabajo:** `backend`  
**Accion:** ejecutar comandos (genera archivos automaticamente, no se copia codigo)

## Por que (contexto)

Este commit es distinto a los demas del proyecto: en vez de copiar
codigo, van a correr comandos que instalan el paquete oficial de
autenticacion de Laravel y generan automaticamente las paginas de
login/registro, controladores de Auth, rutas, etc.

Van a pasar DOS cosas que hay que corregir a mano despues de que
Breeze termine de generar archivos:

1. Breeze crea las paginas en `resources/js/Pages/` (con mayuscula).
   Este proyecto ya usa `resources/js/pages/` (minuscula) desde el
   Producto 02 (para evitar el bug de mayusculas que rompe en Linux).
   Hay que MOVER lo que genero Breeze a la carpeta minuscula que ya
   existe, no dejar las dos carpetas.

2. Verifica que `app/Http/Middleware/HandleInertiaRequests.php` tenga
   un metodo `share()` que incluya `'auth' => ['user' => $request->user()]`.
   Breeze normalmente ya lo agrega solo; si no aparece, agregalo a mano
   — el navbar que va a hacer Karina depende de esto para saber si hay
   sesion iniciada y que rol tiene.


> **Nota:** Cuando el instalador pregunte que framework de pruebas prefieres, elige PHPUnit (ya esta configurado en el proyecto).

## Comandos a ejecutar

```powershell
composer require laravel/breeze --dev
php artisan breeze:install vue

# Windows PowerShell: mover lo que genero Breeze a la carpeta que ya usa el proyecto
Move-Item resources\js\Pages\* resources\js\pages\ -Force
Remove-Item resources\js\Pages -Recurse -Force

npm install
composer dump-autoload
php artisan migrate

git add -A
```
